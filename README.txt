TORNEKO'S GREAT ADVENTURE  -  REMASTERED HD SCRIPT PORT

This is an extensive addendum to the original fan translation done by Magic Destiny.
It incorporates dialogue and terminology from the remaster where appropriate, improves
the font and interface, and expands character entry for the naming screen. (With these
changes came many problems with text and rendering, but everything has been fixed before
release.)



                          //////////PATCHING INSTRUCTIONS//////////
There are two versions of the patch: Dragon Quest, and Dragon Warrior.
The Dragon Quest patch is standard and most of the notes below apply to it; it uses
the Remaster's script and terminology, enemy names, item names, characters, etc. and
also features that signature British English usage Dragon Quest goes for.

The Dragon Warrior patch on the otherhand aims for the feel of an English release from
before 2005. The Remastered script is there, but liberties were taken to change 
British English colloquialisms, spelling, and terminology to be American English as
was used in the Dragon Warrior games. Older localized names take priority over modern
ones (ex. Tessie and Tipper are Nina and Paulo, like they were in Torneko Last Hope)

BOTH PATCHES ARE DIFFERENTIATED BY THE FIRST TWO LETTERS;
DQ = Dragon Quest
DW = Dragon Warrior

BOTH CAN BE PATCHED TO EITHER AN UNEDITED, UNHEADERED JAPANESE ROM - CRC32: 654E1BE4
OR AN UNHEADERED ROM WITH THE MAGIC DESTINY 0.99 PATCH - CRC32: 96064895






                                  Release - 9/24/2026

-Fixed the opening storybook narration that was broken from the Fan Translation. 
(Updated the text after the Remaster released.)

-Created my own font, with HEAVY inspiration from screenshots and recordings of
the "unreleased english prototype" build of the game.

-DQ: Updated Character and Enemy names to match Official Dragon Quest localizations.
(Updated item names too after the Remaster released.)
-DW: Updated Character, Item, and Enemy names to match the feeling of Official Dragon Warrior localizations.

-Revised the remaining untranslated bits leftover from the fan translation, 
like the Title Screen and the Dungeon Floor graphic that shows when entering
dungeons and going down stairs. As well as create my own "Floor" graphic for 
the top left of the screen.

-Created a little stair graphic that looks like what Magic Destiny had in 
their translation at one point (at least, I saw it on a website featuring 
their translation, but it's not in their current patch at all)

-Updated in-dungeon menu to match Officially localized games.
(Moreso now that the remaster released.)

-Updated Dungeon messages so that they can accommodate longer enemy/item names.
(Tested very long names and there appear to be absolutely no overflows.)

-On the naming screens, added additional two pages, (inspired by how the 
Japanese version had multiple pages of symbols). Page 2 is for Letters "Accents"
(Don't ask me why I implemented this, I think I got inspired by Trials of Mana 
when that also got its official translation...), but the feature exists and 
I've ironed out so many bugs regarding it. That feature should be bug free as of February 2026.
Page 3 is for special symbols that people wouldn't use, but it can't hurt to have
it there for people to be creative.

-Also was able to expand the village name character limit to 6 from just 4. (I wanted 7, but that would cause a lot of issues) 

-After 1-to-1 porting the Script, reformatted strings, adjusted window sizes, 
created a contingency for sentences that go above 4 lines of text. 

-Implemented motke's bugfix for the fan translation.

-Also found an issue with two rings displaying the same value, even though one
of them is worthless.

-Other minor behind-the-scenes changes that make sure none of these changes cause
any graphical issues, overflows, or crappy-looking dialogue boxes.

Please do not hesistate to report any bugs or glitches you experience, and be
specific as to which version of the hack you're experiencing it and where.
